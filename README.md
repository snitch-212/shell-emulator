# Эмулятор командной оболочки UNIX

Практическая работа №1 по дисциплине «Конфигурационное управление», вариант 25.

## Общее описание

Консольное приложение (CLI), имитирующее работу командной строки
UNIX-подобной ОС. Язык реализации — Python 3.10+, сторонние библиотеки
не используются.

Текущий этап — **этап 1 (REPL)**: прототип поддерживает диалог с
пользователем, парсер командной строки и команды-заглушки.

## Функции и настройки

### Приглашение к вводу

Строится по реальным данным ОС: `имя_пользователя@имя_хоста:~$`.

### Парсер

| Синтаксис | Поведение |
|-----------|-----------|
| `a b   c` | слова разделяются пробелами |
| `$HOME`, `${HOME}` | раскрытие переменной окружения реальной ОС |
| `'текст $HOME'` | одинарные кавычки — без подстановок |
| `"текст $HOME"` | двойные кавычки — с подстановками |
| `\x` | экранирование символа |
| `# ...` | комментарий до конца строки |

Неизвестная переменная заменяется пустой строкой (как в bash).

### Команды

| Команда | Описание |
|---------|----------|
| `ls [-l] [-a] [путь ...]` | заглушка: выводит имя и аргументы |
| `cd [путь]` | заглушка: выводит имя и аргумент |
| `exit [код]` | завершение работы с кодом возврата |

### Ошибки

| Ситуация | Сообщение | Код |
|----------|-----------|-----|
| неизвестная команда | `foo: command not found` | 127 |
| неверная опция | `ls: invalid option -- 'z'` | 1 |
| лишние аргументы | `cd: too many arguments` | 1 |
| нечисловой код exit | `exit: abc: numeric argument required` | 1 |
| незакрытая кавычка | `shell: syntax error: unterminated quote (")` | 1 |

## Сборка и запуск

Сборка не требуется, нужен Python 3.10 или новее.

```sh
./run.sh          # Linux / macOS
run.bat           # Windows
make run          # через Makefile
```

Тесты и проверка оформления кода:

```sh
make test         # или: python3 -m unittest discover -s tests -t .
make lint         # или: python3 tools/check_style.py
```

## Пример использования

```text
$ ./run.sh
student@laptop:~$ ls -la $HOME "a b"
ls -la /home/student a b
student@laptop:~$ cd /tmp
cd /tmp
student@laptop:~$ cd a b
cd: too many arguments
student@laptop:~$ foo
foo: command not found
student@laptop:~$ exit 5
$ echo $?
5
```

## Структура репозитория

```text
src/shell_emulator/   исходный код
  cli.py              точка входа и параметры командной строки
  shell.py            приглашение, выполнение команд, цикл REPL
  parser.py           разбор строки, кавычки, переменные
  commands/           реализация команд
tests/                модульные тесты (unittest)
tools/check_style.py  проверка кода по правилам оформления
run.sh, run.bat       скрипты запуска
```
