# Эмулятор командной оболочки UNIX

Практическая работа №1 по дисциплине «Конфигурационное управление», вариант 25.

## Общее описание

Консольное приложение (CLI), имитирующее работу командной строки
UNIX-подобной ОС. Язык реализации — Python 3.10+, сторонние библиотеки
не используются.

Текущий этап — **этап 2 (конфигурация)**: эмулятор принимает параметры
командной строки и умеет выполнять стартовый скрипт.

## Функции и настройки

### Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script PATH` | путь к стартовому скрипту |
| `-h`, `--help` | справка по параметрам |

При запуске эмулятор выводит отладочную информацию обо всех параметрах:

```text
[debug] emulator parameters:
[debug]   --vfs     = (not set)
[debug]   --script  = examples/stage2.txt
```

### Стартовый скрипт

Текстовый файл с командами эмулятора, по одной на строку.

* Комментарии — как в Python: строка или хвост строки после `#`.
* Каждая команда выводится вместе с приглашением, затем её вывод —
  получается имитация диалога с пользователем.
* Ошибка в строке выводится с её номером
  (`script.txt: line 6: cd: too many arguments`), выполнение
  продолжается со следующей строки.
* Если файл скрипта не найден или не читается — сообщение
  `shell: cannot read script ...` и код возврата 1.
* Команда `exit` в скрипте завершает эмулятор; иначе после скрипта
  начинается интерактивный режим.

### Приглашение к вводу

Строится по реальным данным ОС: `имя_пользователя@имя_хоста:~$`.

### Парсер

| Синтаксис | Поведение |
|-----------|-----------|
| `a b   c` | слова разделяются пробелами |
| `$HOME`, `${HOME}` | раскрытие переменной окружения реальной ОС |
| `'текст $HOME'` | одинарные кавычки — без подстановок |
| `"текст $HOME"` | двойные кавычки — с подстановками |
| `\x` | экранирование символа |
| `# ...` | комментарий до конца строки |

Неизвестная переменная заменяется пустой строкой (как в bash).

### Команды

| Команда | Описание |
|---------|----------|
| `ls [-l] [-a] [путь ...]` | заглушка: выводит имя и аргументы |
| `cd [путь]` | заглушка: выводит имя и аргумент |
| `exit [код]` | завершение работы с кодом возврата |

### Ошибки

| Ситуация | Сообщение | Код |
|----------|-----------|-----|
| неизвестная команда | `foo: command not found` | 127 |
| неверная опция | `ls: invalid option -- 'z'` | 1 |
| лишние аргументы | `cd: too many arguments` | 1 |
| нечисловой код exit | `exit: abc: numeric argument required` | 1 |
| незакрытая кавычка | `shell: syntax error: unterminated quote (")` | 1 |

## Сборка и запуск

Сборка не требуется, нужен Python 3.10 или новее.

```sh
./run.sh          # Linux / macOS
run.bat           # Windows
make run          # через Makefile
```

Тесты и проверка оформления кода:

```sh
make test         # или: python3 -m unittest discover -s tests -t .
make lint         # или: python3 tools/check_style.py
```

### Скрипты для проверки параметров

Каталог `scripts/` содержит скрипты реальной ОС (`.sh` и `.bat`),
которые вызывают эмулятор со всеми поддерживаемыми параметрами:

| Скрипт | Что проверяет |
|--------|---------------|
| `test_no_params` | запуск без параметров |
| `test_script` | `--script`: комментарии, ошибки, `exit`, нет файла |
| `test_all_params` | `--vfs` и `--script` вместе, `--help`, неверный параметр |

```sh
sh scripts/test_script.sh          # Linux / macOS
scripts\test_script.bat            # Windows
```

## Пример использования

```text
$ ./run.sh
student@laptop:~$ ls -la $HOME "a b"
ls -la /home/student a b
student@laptop:~$ cd /tmp
cd /tmp
student@laptop:~$ cd a b
cd: too many arguments
student@laptop:~$ foo
foo: command not found
student@laptop:~$ exit 5
$ echo $?
5
$ ./run.sh --script examples/exit_code.txt
[debug] emulator parameters:
[debug]   --vfs     = (not set)
[debug]   --script  = examples/exit_code.txt
# Скрипт завершает эмулятор с кодом 3
student@laptop:~$ ls
ls
student@laptop:~$ exit 3
```

## Структура репозитория

```text
src/shell_emulator/   исходный код
  cli.py              точка входа и параметры командной строки
  shell.py            приглашение, выполнение команд, цикл REPL
  parser.py           разбор строки, кавычки, переменные
  commands/           реализация команд
tests/                модульные тесты (unittest)
examples/             стартовые скрипты эмулятора
scripts/              скрипты ОС для проверки эмулятора
tools/check_style.py  проверка кода по правилам оформления
run.sh, run.bat       скрипты запуска
```
